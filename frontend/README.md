# Agrawal Pathology Laboratory — Frontend

Complete React + Vite + TypeScript frontend for the pathology reporting system.

## Run

```bash
npm install
npm run dev
```

Frontend: http://localhost:5173
Backend expected at: http://localhost:8080

## Included

- Dashboard with live counts and recent reports
- Sidebar navigation
- Patient directory with search, create, edit and delete
- Report creation
- Report list with search/status filtering
- Report details and patient summary
- Result entry/editing grouped by section
- Save results to Spring Boot API
- Finalize draft reports
- Open/print generated PDF
- Test master for sections and test definitions
- Responsive layout

## Backend endpoints expected

The frontend is wired to the API exposed by the accompanying Spring Boot backend under `/api`.
